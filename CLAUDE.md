# Project: Clipper Tool

A monthly-subscription web app for clippers: people who cut
short vertical clips from streamers' long-form content.

## Read first
- docs/PLAN.md (scope, stack, architecture, build plan)
- docs/BRANDING.md (name, colors, type, voice)
- docs/DESIGN_PREFERENCES.md (founder likes and dislikes, read before any design work)
- docs/PRD.md and docs/DECISIONS.md once they exist

## Rules
- Ask me questions before building anything non-trivial.
- Do not write code until docs/PRD.md is approved.
- The app never hosts campaigns, holds funds, or pays anyone out.
  Campaign discovery (finding campaigns on other platforms) is a later phase.
- Save every plan, spec, or decision as a .md file in docs/.
  PRD goes in docs/PRD.md, the screen list in docs/SCREENS.md.
- When we decide something, add a dated line to docs/DECISIONS.md.
- Keep each reply short. Tell me what you changed and what you need from me.
